Este repositório é um fork de customização e branding de [DuarteSantos8/openGym](https://github.com/DuarteSantos8/openGym), mantido sob licença AGPL-3.0.

## 1. Princípios de Isolamento
- As superfícies visuais web e configurações de branding utilizam a marca **PR Fit**.
- Nomes técnicos (IDs de pacotes mobile, rotas de API interna e esquemas de dados) são preservados para permitir merges limpos com o upstream.
